《元素诀》是一款以五行相克、身份转换与道具博弈为核心的多人策略卡牌游戏。选择金、木、水、火、土中的一种身份，以七点生命进入战局，利用元素克制突破防守，也可以消耗攻击机会更换身份，调整自己的攻防策略。 环形座位决定攻击距离，丰富的道具让战局充满变化：预置护盾抵挡攻击，打出无效化解危机，或用悬赏借助他人的进攻获取手牌。你需要观察对手的身份、血量与出牌节奏，在有限的行动机会中决定进退。 游戏支持2—5人自由混战和4人2v2组队，可邀请好友联机，也可添加简单、中等、困难三档人机。中世纪手绘与拜占庭圣像美术，搭配金箔、羊皮纸、七盏生命圣灯，以及圣咏、战鼓与摇滚元素交织的配乐，营造庄严而激烈的五行决战。
