# 元素诀

《元素诀》是一款以五行相克、身份转换与道具博弈为核心的多人策略卡牌游戏。选择金、木、水、火、土中的一种身份，以七点生命进入战局，利用元素克制突破防守，也可以消耗攻击机会更换身份，调整自己的攻防策略。 环形座位决定攻击距离，丰富的道具让战局充满变化：预置护盾抵挡攻击，打出无效化解危机，或用悬赏借助他人的进攻获取手牌。你需要观察对手的身份、血量与出牌节奏，在有限的行动机会中决定进退。 游戏支持2—5人自由混战和4人2v2组队，可邀请好友联机，也可添加简单、中等、困难三档人机。中世纪手绘与拜占庭圣像美术，搭配金箔、羊皮纸、七盏生命圣灯，以及圣咏、战鼓与摇滚元素交织的配乐，营造庄严而激烈的五行决战。

## 本地运行

需要 Node.js 22 或更新版本（房间接口使用内置的 `node:sqlite`）。

```bash
npm start
```

浏览器打开 http://127.0.0.1:4173 。首页对应 `client/game.html`，图片在 `public/assets`，联机接口是同源的 `/api/rooms`，数据写在本机 `.local-data/rooms.sqlite`。

同一局域网里一起玩时，可以这样启动，再用这台电脑的局域网地址加入：

```bash
HOST=0.0.0.0 npm start
```

本机对战和三档人机都在浏览器里结算，不需要账号。

## 线上站点

公开地址：https://fan999-99.github.io/EC/

图片和房间接口都相对当前页面解析，因此放在域名根目录，或放在 GitHub 项目页的 `/EC/` 下，都能找到 `assets/`。

线上可以直接玩本机对战和人机。联机房间需要与网页同一来源的 `/api/rooms`，以及一块持久数据库（原设计是 Cloudflare D1）。这次没有可用的数据库凭证，所以公开页面不提供联机，也不会把请求转到其他网站。打开「房间联机」时会直接说明。`npm start` 会在本机用 SQLite 提供这个接口。

`npm run build` 生成 `site/`（`index.html` 与 `assets/`）。GitHub Pages 使用 `gh-pages` 分支的根目录。合并到 `main` 之后，Actions 会重新构建并更新该分支。请在仓库 Settings → Pages 里选择分支 `gh-pages`、目录 `/ (root)`。

## 离线单文件

Windows 便携版里的 `offline.html`（约 24.8MB，自带全部资源）没有放进这个仓库。网页上不再提供「离线版」下载，避免指向一个不存在的文件。请直接在浏览器中游玩。

## 目录

- `client/game.html`：游戏页面
- `public/assets`：第八版 webp（立绘、元素牌、道具、标志）和壁画
- `server/`、`drizzle/`：房间逻辑与表结构
- `local-server.mjs`：静态文件与 `/api/rooms`
